# Сайт центра развития детей «Наше Будущее» (Гудермес)

Читай этот файл и ДЕПЛОЙ.md в начале каждой сессии, чтобы продолжить с того места, где остановились.

## Как общаться с владельцем проекта
- По-русски, простыми словами, без жаргона. Владелец не разработчик.
- Шаг за шагом: одно действие за сообщение, потом ждать скриншот или ответ. Не выдавать весь план сразу.
- Не пропускать этапы. Если что-то непонятно в интерфейсе, просить скриншот, а не гадать.
- Когда просят «закоммить», коммитить и пушить в origin/main.

## Что это за проект
- PHP-сайт без базы: `index.php` (страница), `admin/` (админка), `data/content.json` (всё содержимое), `uploads/` (фото), `assets/` (стили, скрипт, логотип, видео первого экрана), `inc/` (служебное).
- Форма заявки ничего не отправляет на сервер: открывает WhatsApp с готовым текстом.
- Инструкция для владельца: `ИНСТРУКЦИЯ.md`. План выкладки и статус: `ДЕПЛОЙ.md`.
- `index.html` в корне нужен только для GitHub Pages (статичный слепок). Админка и пересборка там не работают.

## Правила, которые нельзя нарушать
- В архивы для хостинга не класть `data/config.php`, `data/login.json`, `data/backups/`, а также не перезаписывать `data/content.json` и `uploads/` на хостинге: там правки владельца из админки, новее, чем в git.
- Пароль админки в чат не просить и не сохранять.
- Данные владельца домена (паспорт и т. п.) вводит и подтверждает он сам.
- Фото и видео с детьми публиковать только с согласием родителей. Лица детей на видео размыты.
- Волосы специалисток под платком на фото затемнены и размыты (Цагаева, Кадырова, Газиева). Исходники в git до коммита b15334e.
